# 전투 시뮬레이터 (BattleSim)

Unity를 켜지 않고 실제 게임 전투 코드(`Assets/Scripts`의 BattleManager, Deck, Enemy, 데이터베이스 등)를 그대로 컴파일해서 돌리는 도구다. 2026-11-11에 전투가 시간 기반(이동 + 덱, 공격 턴과 정비)으로 바뀌면서, 예전 턴 방식으로 계산하던 `Tools/BalanceSim`의 승률을 대신한다.

게임 코드를 복사하지 않고 원본 파일을 직접 컴파일하므로, 카드·적·시간 숫자를 바꾸면 다음 실행부터 바로 반영된다.

## 실행

PowerShell에서 저장소 폴더 기준으로 실행한다. 처음 한 번은 빌드 때문에 몇 초 더 걸린다.

```powershell
.\Tools\BattleSim\run.ps1            # 승률표
.\Tools\BattleSim\run.ps1 check      # 전투 흐름 18항목 확인
```

.NET SDK는 Unity 에디터에 들어 있는 것(`Unity\Hub\Editor\<버전>\Editor\Data\DotNetSdk`)을 쓰니 따로 설치할 필요가 없다.

## 두 가지 모드

**check**는 시간 기반 전투 규칙을 하나씩 확인한다. 이동과 카드가 정해진 시간을 쓰는지, 적이 속도에 맞춰 움직이는지, 코스트를 다 쓰면 정비로 넘어가는지, 정비에 들어갈 때 남은 덱에서 손패를 채우는지, 정비가 끝나면 코스트가 돌아오는지, 승패가 한 번만 정해지는지 등 18항목이다. 하나라도 실패하면 종료 코드 1을 돌려준다. 시간 숫자를 바꿔도 통과하도록 BattleManager의 값을 읽어서 비교한다.

**balance**(기본값)는 층마다 일반 1마리, 일반 2마리, 집단 3마리(각 1/3), 엘리트, 보스와 직업 4종을 여러 판 싸워 승률과 잃은 체력을 표로 보여 준다. 적 구성은 FloorGenerator의 층별 목록을 그대로 쓴다.

## 옵션 (balance)

| 옵션 | 뜻 |
|---|---|
| `--battles N` | 직업·상대마다 판 수 (기본 200) |
| `--layer 1~3` | 한 층만 |
| `--class 전사` | 한 직업만 (전사·도적·마법사·성기사 또는 Warrior 등) |
| `--seed N` | 난수 시드 (같은 시드면 같은 결과) |
| `--move` `--card` `--recovery` `--recovery-move` | 시간 숫자를 코드 수정 없이 바꿔 보기 (BattleManager 맨 위 값) |
| `--snapshots 경로` | 덱 표본 파일 지정 |
| `--verbose` | 게임 로그 출력 (판 수를 줄여서 쓸 것) |

## 덱 표본 (snapshots.json)

2·3층 전투에는 그 시점까지 자란 덱이 필요하다. 덱 성장(보상 카드, 유물, 레벨, 마법사 마나)은 `Tools/BalanceSim/balance-sim.js`가 런을 600판씩 굴려 계산하고, 직업마다 '층 시작'과 '보스 직전' 시점의 상태를 40개씩 `snapshots.json`으로 내보낸다. 보스전은 '보스 직전 덱', 나머지는 '층 시작 덱'으로 싸운다.

카드·직업·보상 규칙을 바꿨으면 표본을 다시 만든다.

```powershell
node Tools/BalanceSim/balance-sim.js
```

이 명령은 `Tools/BalanceSim/result.json`도 다시 쓴다. 적 수치를 바꾸는 `--apply`는 붙이지 않는 한 실행되지 않는다.

## 사람 대신 싸우는 규칙과 한계

전투는 플레이어가 방 가장자리에서 들어와 첫 적과 맞닿은 채로 시작하고, 나머지 무리원은 5x5 방 안 아무 칸에 있다. 체력과 코스트는 가득 찬 상태다. 플레이어는 쓸 수 있는 카드 중 코스트 대비 가치(피해, 들어올 피해만큼의 방어, 회복, 드로우 등)가 가장 높은 카드를 내고, 막타를 칠 수 있으면 그 적을 노린다. 카드가 사거리 밖이면 가까운 적에게 한 칸 다가가고, 쓸 카드가 없으면 턴을 끝내며, 정비 시간은 기다리지 않고 넘긴다.

사람보다 단순하게 싸우므로 실제 플레이보다 승률이 조금 낮게 나올 수 있다. 도주, 맵에서 미리 쓰는 카드, 음식, 방어막을 들고 전투에 들어가는 경우는 다루지 않는다. 같은 조건에서 숫자를 바꾸기 전과 후를 비교하는 용도로 쓰는 것이 가장 정확하다.
